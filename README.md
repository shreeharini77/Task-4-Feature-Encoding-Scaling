# Task-4-Feature-Encoding-Scaling

## Internship: AI & ML Internship  
## Dataset: Adult Income Dataset

---

## 📌 Objective
The objective of this task is to preprocess the Adult Income dataset by
cleaning the data, encoding categorical features, scaling numerical features,
and preparing the dataset for machine learning models.

---

## 📊 Dataset Description
The Adult Income dataset contains information about individuals such as:
- Age
- Workclass
- Education
- Occupation
- Working hours
- Income level (<=50K or >50K)

Each row represents one individual.

---

##  Tools & Libraries Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib (for visualization)

---

##  Steps Performed

1. Loaded the Adult Income dataset using Pandas  
2. Handled missing values by removing unknown entries  
3. Identified categorical and numerical features  
4. Applied Label Encoding to the target column (income)  
5. Applied One-Hot Encoding to categorical features  
6. Scaled numerical features using StandardScaler  
7. Compared data before and after scaling  
8. Saved the final processed dataset for machine learning use
